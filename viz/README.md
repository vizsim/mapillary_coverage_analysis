# Mapillary Coverage Analysis – Karte

Interaktive Karte zur Mapillary-Abdeckung auf Hauptstraßen in Deutschland: je nach Zoomstufe siehst du Bundesländer, Landkreise oder Gemeinden, dazu Straßensegmente mit Panorama-, Regulär- oder fehlender Abdeckung sowie erkannte Verkehrszeichen.
